# Embedded Practice
Studying for interviews for embedded software engineering positions. Some resources are listed below:

- [Topic Website](https://embeddedinterviewlab.com/): kind of like LeetCode (AI generated though) with more emphasis on topics

> [!NOTE] Most of these problems were generated as a LeetCode style problem statement with Claude. The testing harnesses
> were also autogenerated. All solutions and actual code was written by me though.

## Practice Problems
### Bit Manipulation and Operations
`crc8.c`: cyclical redundancy check 
`endian.c`: endian test and swap bytes

### Linked Lists
`cycle_ll.c`: cycle detection in linked lists
`reverse_ll.c`: reverse a linked list in place

### Ring Buffers
`ring_buffer.c`: ring/circular buffer implementation
`moving_average.c`: moving average implementation using a ring buffer

### State Machines
`slip.c`: byte buffer encoder and decoder with escape characters
`streaming_parser.c`: payload packet parser
### Other
`itoa.c`: integer to string conversion
`time_after.c`: checking time intervals using `uint32_t` with wraparounds
